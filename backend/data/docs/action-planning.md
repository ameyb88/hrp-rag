# Action Planning

The Action Planning module helps healthcare leaders track improvement efforts.

## Key Features

- Create new action plans from events, analyses, or lessons.
- Assign owners, set due dates, and track completion.
- Prioritize by urgency (Critical, High, Medium, Low).

## Workflow

1. From the dashboard, click **New Action Plan**.
2. Enter a title, description, and link it to an event.
3. Assign an owner from your team.
4. Add milestones and due dates.
5. Monitor progress in the Action Planning dashboard.

## Tips

- Use the **priority flag** to highlight urgent work.
- Plans appear in team dashboards automatically.
