# Patient Safety Events

Track frontline-reported safety events to spot risks early.

## Key Features

- Quick form entry on web or mobile.
- Categories: Medication, Fall, Equipment, Other.
- Option to submit anonymously.

## Submitting

1. Go to **Patient Safety Event Reporting**.
2. Fill required fields (category, description).
3. Attach screenshots or files if needed.
4. Submit for review.
