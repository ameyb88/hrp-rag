# Cause Analysis

Cause Analysis uncovers why an event occurred and prevents recurrence.

## Key Features

- Step-by-step wizard to capture contributing factors.
- Causal factor coding aligned with HRP taxonomy.
- Export analysis for committee review.

## Workflow

1. Select the event from the Events list.
2. Click **Start Cause Analysis**.
3. Complete each wizard step:
   - Event details
   - Contributing factors
   - Root cause
4. Save and publish.
