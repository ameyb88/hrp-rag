# Incident Response (SEV Process)

## Severity

- SEV1: customer-visible outage
- SEV2: major degradation
- SEV3: minor impact

## Workflow

1. **Declare** in #incidents with severity.
2. **Create** incident ticket (owner = Incident Commander).
3. **Mitigate** first, then fix.
4. **Comms:** status every 30m (SEV1) / 60m (SEV2).
5. **Postmortem** within 5 business days.

## Postmortem Template

- Impact, Timeline, Root cause, Actions (owner + due date), Lessons.
