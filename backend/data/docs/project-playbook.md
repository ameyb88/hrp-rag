# Project Launch Playbook

## Phases

- **Discovery:** scope, risks, success metrics.
- **Build:** milestones, owners, weekly demos.
- **Launch:** release notes, comms, rollback plan.
- **Post-launch:** KPIs + retro.

## Weekly Rhythm

1. Monday planning
2. Daily standup
3. Friday demo + notes

## Roles

- PM (scope), Eng Lead (delivery), QA (quality).

## Exit Criteria

- KPIs met
- Incident docs updated
- Support handoff complete
