# Engineering Onboarding

## Goal

Get a new engineer productive in Day 1–3.

## Checklist

1. Request laptop + SSO account.
2. Join Slack channels: #eng, #releases, #incidents.
3. Install: Git, Node LTS, Docker, VS Code.
4. Clone the monorepo and run `npm ci`.
5. Run `npm start` to boot the dev server.

## Tips

- Use the Team Handbook for coding standards.
- Ask questions in #eng-help.
